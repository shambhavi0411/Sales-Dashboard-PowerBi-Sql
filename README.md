# Pizza Sales Dashboard | Power BI + SQL

# Overview
Pizza sales analysis dashboard built using Power BI, SQL and CSV dataset.

# Tools Used
- Power BI
- SQL
- CSV Dataset

# KPIs
- Total Revenue
- Average Order Value
- Total Orders
- Total Pizza Sold
- Average Pizza Per Order

# Analysis
- Daily Order Trend
- Monthly Trend
- Sales by Category
- Sales by Pizza Size
- Top & Bottom Performing Pizzas

## Files Included
- Sales Dashboard.pbix
- pizza_sales.csv
- PIZZA SALES SQL QUERIES.txt
