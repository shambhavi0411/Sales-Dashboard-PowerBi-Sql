PIZZA SALES SQL QUERIES - OUTPUTS & INSIGHTS

Dataset: pizza_sales.csv | Records: 48,620 | Tool: SQL

A1. Total Revenue
SQL Query:
  SELECT SUM(total_price) AS Total_Revenue FROM pizza_sales;

Output:
  Total_Revenue  
  817,860.05     
Insight: Total revenue generated is $817,860.05 across the full dataset.

A2. Average Order Value
SQL Query:
  SELECT (SUM(total_price)/COUNT(DISTINCT order_id)) AS Avg_order_Value FROM pizza_sales;

Output:
  Avg_Order_Value  
  38.31            
Insight: On average, each order is worth $38.31.

A3. Total Pizzas Sold

A5. Average Pizzas Per Order
SQL Query:
  SELECT CAST(CAST(SUM(quantity) AS DECIMAL(10,2)) / CAST(COUNT(DISTINCT order_id) AS DECIMAL(10,2)) AS DECIMAL(10,2)) AS Avg_Pizzas_per_order FROM pizza_sales;

Output:
  Avg_Pizzas_per_order  
  2.32                  
Insight: On average, customers order 2.32 pizzas per order.

D. % of Sales by Pizza Category
SQL Query:
  SELECT pizza_category, CAST(SUM(total_price) AS DECIMAL(10,2)) AS total_revenue,
  CAST(SUM(total_price) * 100 / (SELECT SUM(total_price) FROM pizza_sales) AS DECIMAL(10,2)) AS PCT
  FROM pizza_sales
  GROUP BY pizza_category;

Output:
  pizza_category  total_revenue  PCT    
  Classic         220,053.10     26.91  
  Supreme         208,197.00     25.46  
  Chicken         195,919.50     23.96  
  Veggie          193,690.45     23.68  

Insight: Classic category leads with 26.9% of total sales, closely followed by Supreme, Chicken, and Veggie categories, which are fairly evenly split.

E. % of Sales by Pizza Size
SQL Query:
  SELECT pizza_size, CAST(SUM(total_price) AS DECIMAL(10,2)) AS total_revenue,
  CAST(SUM(total_price) * 100 / (SELECT SUM(total_price) FROM pizza_sales) AS DECIMAL(10,2)) AS PCT

  XXL         1,006.60       0.12   

Insight: Large pizzas drive the most revenue at 45.9% of total sales, more than double the smallest sizes combined.
